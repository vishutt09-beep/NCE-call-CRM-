How to use NCE Caller

નવા Staff અને Admin માટે સરળ માર્ગદર્શન

1 · Call કેવી રીતે કરવો?

Calls → Pending Customer પસંદ કરો → Call દબાવો. Phone Dialer ખુલશે. Call પછી CRM માં પાછા આવી Response Save કરો.

2 · Response ક્યાં જશે?

Interested / No Answer / Call Back પસંદ કરો, Quick Notes પસંદ કરો અને Save કરો. Number Pending માંથી દૂર થઈ સંબંધિત Folder માં દેખાશે. Save પછી Next Call લઈ શકાય.

3 · Follow-up ક્યાં મળશે?

Follow-ups માં આજના અને Overdue Numbers જુઓ. સમય પ્રમાણે Date બદલો અથવા Complete કરો. માત્ર CRM ખોલેલું હોય ત્યારે In-App Notification દેખાય છે.

4 · Admin ને બધું ક્યાં મળશે?

Home → Staff-wise Work અને Notes. All Features માંથી Excel Import, Create Staff, Reports, Targets, Messages, Number Transfer અને Backup સીધા ખોલો.
